# Model and implementation

## Main CM-BARS configuration

The primary entry point is `api.model()`, which constructs `CMBARS2(use_gp=False, warmup=1000, samples=1000, chains=2, seed=0)`. The low-level constructor retains the original research defaults, so use the API factory or `run.py` for the manuscript configuration.

For adsorption fraction q = y/100, the likelihood is a point mass at zero with probability π, and a Beta distribution with mean μ and precision φ otherwise. Overall expected adsorption is 100(1−π)μ; conditional positive adsorption is 100μ. The two targets should not be interchanged in optimization.

The positive logit uses a nine-term quadratic basis. The 3 × 9 coefficient matrix is ΛΦ + Δ with two shared directions, signed loadings, and compound-specific deviations. Linear, quadratic, and interaction terms have separate half-normal scale priors. The zero logit uses a shared linear factor direction and signed compound loadings. Intercept prior centers are calculated from the current training set only.

The implementation retains the original numerical conventions: positive means are clipped to [1e−5, 1−1e−5], zero logits to [−12,12], input fractions to [1e−6,1−1e−6], and per-observation log likelihoods are floored at −60. Prediction also floors Beta shape parameters at 1e−3. Sampling therefore uses the stated working posterior and numerical sampling conventions.

## Components and comparisons

`code/cmbars.py` implements the raw-scale Tobit-MT-Bayes comparator. The main hurdle-Beta implementation is `code/cmbars2.py`. `methods.py` supplies OLS, clipped OLS, regularized quadratics, PLS, tree ensembles, a Matérn GP, and a single-task Tobit model. Predictive intervals use the respective constructions described in the manuscript; OLS intervals do not include leverage or small-sample t quantiles.

Benefits are response-dependent. In the saved LOCO results, the bounded likelihood and blockwise shrinkage improve average RMSE, and low-rank sharing mainly helps acetosyringone. Removing the zero part slightly lowers average RMSE but worsens average CRPS. ExtraTrees has lower mean point error than CM-BARS.

## PFN-RSM

The network has 19 input features, six Transformer layers, eight attention heads, hidden width 128, feedforward width 256, and a five-Gaussian mixture output. Training draws synthetic quadratic, GP-dominated, sparse, and uncensored scenarios with default proportions 3:1:1:1. Training normalization uses context responses only. Query tokens attend to context and themselves, never to other queries' responses.

The prior uses Gaussian noise and zero clipping. It is distinct from the hurdle-Beta prior. The bundled checkpoint has 50,000 steps and batch size 256. Predictive samples are converted to percentages and clipped to [0,100].

## Historical pooling and distillation

`stack_oof.py` preserves cached CM-BARS+ experiments. Weight-selection caches may have been generated by models trained on the current test condition. Their scores are not unbiased outer-fold estimates. `run.py cv` excludes this extension to keep the main evaluation independent.

`final_fit.py` retains the historical combined workflow, including all members, pooled surfaces, and distillation. Its optimum calculation maximizes the latent positive-response surface, not overall expected adsorption. Its diagnostics use the conventional Gelman–Rubin calculation, not rank-normalized split R-hat. For a main-model-only fit use `run.py fit`.

## Release engineering changes

Model likelihoods, priors, and sampling equations were retained from the research source. Changes add validated CSV inputs, portable posterior files, a CLI, isolated run snapshots, configuration-sensitive caches, lazy optional-model imports, safer checkpoint loading, and documentation consistent with the final manuscript. Failed cached fits are retried and failed validation runs return a nonzero status. Original source hashes are recorded in `source_manifest.json`.
